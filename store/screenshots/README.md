# App Store screenshots

Drop final ASC-sized PNGs here before submission (not required in git).

Typical Mac sizes (confirm in App Store Connect):
- 1280 × 800
- 1440 × 900
- 2560 × 1600 (2× of 1280 × 800)

Capture tips:
1. Build a MAS or release app: `./scripts/package-app.sh --mas`
2. Open Standing from the menu bar on a clean desktop wallpaper
3. Capture Settings, glance menu, and Activity with `⌘⇧4` then crop

Optional automation starting point: `../scripts/capture_screenshots.py`
